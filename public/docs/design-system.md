# Firefly Design System 设计规范

> 版本：1.0.0  
> 最后更新：2026-07-20  
> 基于规范：TRAE Work 设计系统

## 概述

Firefly Design System 是一套完整的界面设计系统，用于规范产物的设计风格。它包含以下核心组成部分：

- **主题**：定义视觉风格的基础配置，包括主题色、字体、字号、间距、圆角、阴影等设计变量
- **图形**：视觉资源，包括图标、SVG、插画等
- **组件**：基于主题和图形组合形成的可复用界面元素
- **设计规范**：说明主题、图形和组件使用规则的文档

---

## 设计原则

### 1. 一致性

确保视觉和交互体验的一致性：

- 使用统一的颜色、字体、间距和圆角
- 保持组件状态（hover、active、disabled）的一致表现
- 遵循统一的命名和代码风格

### 2. 可访问性

遵循 WCAG 2.1 AA 级别无障碍标准：

- **色彩对比度**：文本与背景的对比度至少达到 4.5:1
- **焦点管理**：所有交互元素都应有清晰的焦点状态
- **键盘导航**：支持完整的键盘操作
- **屏幕阅读器**：提供适当的 ARIA 标签

### 3. 响应式设计

支持从移动端到桌面端的全响应式设计：

- 采用 Mobile First 策略
- 使用 Fluid 响应式策略
- 确保在 320px 到 1536px 屏幕宽度下的良好体验

### 4. 可扩展性

支持主题定制和组件扩展：

- 使用 CSS 变量便于主题覆盖
- 组件支持多种变体和尺寸
- 预留扩展接口

### 5. 性能优先

优化渲染性能和加载速度：

- 最小化 CSS 和 JS 体积
- 使用 GPU 加速动画
- 避免过度使用阴影和模糊效果

## 主题使用规范

### 颜色系统

#### 主题色

主题色使用 `oklch` 色彩空间，通过 `--hue` 变量控制色相：

```css
/* 亮色主题 */
--primary: oklch(0.70 0.14 var(--hue));

/* 暗色主题 */
--primary: oklch(0.75 0.14 var(--hue));
```

#### 语义色

| 用途   | 色相 | 使用场景                     |
|--------|------|------------------------------|
| 成功   | 150  | 成功消息、完成状态           |
| 警告   | 45   | 警告提示、需要注意的信息     |
| 错误   | 25   | 错误消息、验证失败           |
| 信息   | 210  | 提示信息、帮助文本           |

#### 使用建议

- ✅ 使用 CSS 变量：`color: var(--primary)`
- ❌ 不要硬编码颜色值：`color: #10b981`
- ✅ 为交互状态提供反馈：hover、active、disabled
- ❌ 不要在亮色模式下使用低对比度颜色

### 字体系统

#### 字体族

| 类型    | 使用场景                     |
|---------|------------------------------|
| sans    | 正文、按钮、导航             |
| serif   | 文章正文、引用               |
| mono    | 代码、技术内容               |
| display | 标题、宣传语                 |

#### 字号

遵循 Tailwind CSS 默认字号系统：

| 类名    | 大小   | 使用场景         |
|---------|--------|------------------|
| text-xs | 12px   | 辅助文本、标签   |
| text-sm | 14px   | 小号正文、元数据 |
| text-base | 16px | 正文、表单       |
| text-lg | 18px   | 副标题           |
| text-xl | 20px   | 小标题           |
| text-2xl | 24px | 标题             |

### 间距系统

使用 4px 为基础单位，遵循 Tailwind CSS 间距系统：

```css
/* 使用 Tailwind 类名 */
<div class="p-4 m-2 gap-3">

/* 或使用 CSS 变量 */
<div style="padding: var(--spacing-4)">
```

#### 常用间距

| 变量          | 值     | 使用场景         |
|---------------|--------|------------------|
| spacing-1     | 4px    | 紧凑间距         |
| spacing-2     | 8px    | 小间距           |
| spacing-3     | 12px   | 标准间距         |
| spacing-4     | 16px   | 常用间距         |
| spacing-6     | 24px   | 大间距           |
| spacing-8     | 32px   | 区域间距         |

### 圆角系统

| 变量       | 值     | 使用场景             |
|------------|--------|----------------------|
| radius-sm  | 2px    | 小型元素、标签       |
| radius-md  | 6px    | 输入框、按钮         |
| radius-lg  | 8px    | 卡片、下拉菜单       |
| radius-xl  | 12px   | 大型卡片、弹窗       |
| radius-2xl | 16px   | 模态框、大型面板     |
| radius-full| 9999px | 药丸形、圆形         |

## 图形使用规范

### 图标

#### 图标库

推荐使用 [Iconify](https://iconify.design/)，支持多种图标集：

- Material Design Icons
- Heroicons
- Lucide Icons
- Tabler Icons

#### 图标尺寸

| 类名     | 大小   | 使用场景             |
|----------|--------|----------------------|
| icon-xs  | 12px   | 内联图标、角标       |
| icon-sm  | 16px   | 按钮图标、列表图标   |
| icon-md  | 20px   | 标准图标             |
| icon-lg  | 24px   | 导航图标、功能图标   |
| icon-xl  | 32px   | 大型图标、空状态     |

#### 使用建议

- ✅ 图标应配合文字标签，除非含义显而易见
- ✅ 保持图标颜色与文本颜色一致
- ❌ 避免在同一界面混用不同风格的图标

### 插画

#### 插画风格

推荐使用 **minimal** 风格：

- 扁平化设计
- 简洁的线条和形状
- 统一的配色方案

#### 插画尺寸

| 预设    | 尺寸          | 使用场景         |
|---------|---------------|------------------|
| small   | 200×200       | 小型插画         |
| medium  | 400×300       | 卡片插画         |
| large   | 800×600       | 页面插画         |
| hero    | 1200×630      | 头图、OG 图片    |

## 组件使用规范

### 按钮 Button

#### 变体

| 变体       | 使用场景                             |
|------------|--------------------------------------|
| primary    | 主要操作、提交、确认                 |
| secondary  | 次要操作、取消                       |
| outline    | 辅助操作、次要按钮                   |
| ghost      | 低优先级操作、文字按钮               |
| link       | 链接样式按钮                         |
| destructive| 危险操作、删除                       |

#### 尺寸

| 尺寸 | 使用场景         |
|------|------------------|
| sm   | 紧凑布局、表格   |
| md   | 标准尺寸         |
| lg   | 强调按钮、CTA    |
| icon | 仅图标按钮       |

#### 状态

- **Default**：默认状态
- **Hover**：鼠标悬停，轻微变暗
- **Active**：按下状态，明显变暗
- **Disabled**：禁用状态，50% 不透明度，cursor: not-allowed
- **Loading**：加载状态，显示 spinner 和可选的加载文本

### 输入框 Input

#### 变体

| 变体      | 使用场景               |
|-----------|------------------------|
| default   | 标准输入框             |
| filled    | 填充式输入框           |
| underline | 下划线输入框           |

#### 状态

- **Default**：灰色边框
- **Focus**：主题色边框，带发光环
- **Error**：红色边框，显示错误消息
- **Disabled**：灰色背景，禁用光标

### 卡片 Card

#### 变体

| 变体        | 使用场景                     |
|-------------|------------------------------|
| default     | 标准卡片                     |
| elevated    | 带阴影的提升卡片             |
| bordered    | 带边框的卡片                 |
| interactive | 可点击的交互卡片             |

#### 使用建议

- ✅ 卡片内边距使用 `var(--spacing-lg)` (16px)
- ✅ 圆角使用 `var(--radius-2xl)` (16px)
- ✅ 交互卡片应提供 hover 和 active 状态反馈
- ❌ 避免在卡片内嵌套过多层级

### 弹窗 Dialog

#### 尺寸

| 尺寸 | 宽度   | 使用场景         |
|------|--------|------------------|
| sm   | 400px  | 确认对话框       |
| md   | 500px  | 表单弹窗         |
| lg   | 600px  | 大型表单         |
| xl   | 800px  | 复杂表单、详情   |
| full | 100%   | 全屏弹窗         |

#### 动画

- **Enter**：fade-in + zoom-in-95
- **Exit**：fade-out + zoom-out-95
- **Overlay**：半透明黑色遮罩，4px 模糊

### 断点

| 断点 | 宽度    | 设备           |
|------|---------|----------------|
| xs   | 320px   | 小型手机       |
| sm   | 480px   | 标准手机       |

| xl   | 1280px  | 桌面           |
| 2xl  | 1536px  | 大屏桌面       |

### 容器宽度

```css
/* 移动端：100% 宽度 */
.container { width: 100%; }

/* 桌面端：固定宽度 */
@media (min-width: 1024px) {
  .container { width: 1024px; }
}

@media (min-width: 1280px) {
  .container { width: 1280px; }
}

@media (min-width: 1536px) {
  .container { width: 1536px; }
}
```

## 无障碍指南

### WCAG 2.1 AA 级别要求

#### 可感知 Perceivable

1. **文本替代**：为非文本内容提供替代文本
2. **时基媒体**：为音频和视频提供替代方案
3. **适应性**：创建可以以不同方式呈现的内容
4. **可辨别**：使用户更容易看到和听到内容

#### 可操作 Operable

1. **键盘可访问**：所有功能可通过键盘访问
2. **充足的时间**：为用户提供足够的时间阅读和使用内容
3. **癫痫发作**：不要设计会导致癫痫发作的内容
4. **导航**：帮助用户导航、查找内容和确定位置

#### 可理解 Understandable

1. **可读**：使文本可读和可理解
2. **可预测**：使页面以可预测的方式出现和操作
3. **输入帮助**：帮助用户避免和纠正错误

#### 健壮 Robust

1. **兼容**：最大化与当前和未来用户代理的兼容性

### 实现要点

#### 焦点管理

```css
/* 确保焦点状态清晰可见 */
*:focus-visible {
  outline: 2px solid var(--primary);
  outline-offset: 2px;
}
```

#### ARIA 标签

```html
<!-- 按钮应提供可访问名称 -->
<button aria-label="关闭菜单">
  <icon />
</button>

<!-- 表单字段应有标签 -->
<label for="email">邮箱地址</label>
<input id="email" type="email" aria-describedby="email-hint" />
<span id="email-hint">我们会向此邮箱发送验证码</span>
```

#### 键盘导航

- 使用 `Tab` 键在交互元素间移动
- 使用 `Enter` 或 `Space` 激活按钮
- 使用 `Esc` 关闭模态框和下拉菜单
- 使用方向键在菜单项间导航

## 设计令牌 Naming Convention

使用 `kebab-case` 命名约定：

```css
/* 推荐 ✅ */
--primary-color
--button-padding
--card-border-radius

/* 避免 ❌ */
--primaryColor
--ButtonPadding
--cardBorderRadius
```
